Hi everyone!  
This week, I joined **picoCTF** — my very first Capture The Flag (CTF) competition.

It’s only been **two days** since I started, and so far, I’ve completed **2 challenges** with a total score of **150 points**.  
The experience has been both challenging and exciting, particularly in learning to think like an attacker while applying the cybersecurity concepts I’ve studied.

I’m currently exploring the **Web Exploitation** category, and I’ve already learned how to:
- Test and analyse HTTP connections using `curl`
- Inspect API responses with `jq`
- Understand how developer backdoors can reveal sensitive data

This is just the beginning — my goal is to keep improving and document my progress here as I continue learning.
You can view the work I have done in my repository. [picoCTF_xraysx](https://github.com/eryanom/picoCTF_xraysx)


Stay tuned for updates on my picoCTF journey!
